# fapi-nextbike

## 0. Starting

```bash
git clone <repository_url>
cd fapi-nextbike
```

## 1. Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 2. Windows

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

## 3. Dependencies

```bash
pip install -r requirements.txt
```

## 4. Run

```bash
python main.py
```
